# SKS Admin Guide

Open `/admin` on the production domain and sign in with the owner account.

## Products

1. Select **Add product**.
2. Enter the name, price, material and description. The product code is generated by the server after saving.
3. Enter one size and select **Add Size**. Repeat for every size.
4. Use the arrow buttons to reorder sizes. Clear **Available** to show an out-of-stock size without deleting it.
5. Upload the original product image. Use aspect ratio, fit, zoom, movement and rotation controls to adjust presentation.
6. Select **Preview Product** to check mobile or desktop appearance before saving.
7. Choose Draft, Published or Archived status.

Archiving preserves the product code and historical sales. Codes are never reused.

## Site settings

- Toggle the loading animation on or off.
- Change the product-code prefix for future products.
- Upload, resize, align or remove the logo.
- Change practical theme colours. Resolve any contrast warning before publishing.
- Update the hero, WhatsApp number and social links.

## Sales monitoring

Buy Now clicks are recorded automatically. They are not counted as sales. Enter completed orders through **Record a confirmed sale**. Use **Sync now** after connecting Google Sheets.
